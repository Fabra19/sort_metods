Данный проект был написан в целях изучения различных видов сортировок и логирования.

Помимо изучения сортировок, также рассматривалась сложность этих алгоритмов. Основные типы сложности: квадратичная и логарифмическая.

Для логирования использовался внешний модуль loguru.

This project was written to study various types of sorting and logging.

In addition to studying sorting algorithms, the complexity of these algorithms was also examined. The main types of complexity are quadratic and logarithmic.

The external loguru module was used for logging.
